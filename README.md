`{poldis}`: an R package that provides tools for analyzing political
discourses over time!

# Data

This branch contains *only* the raw data used in the package and/or
analysis. Please refer to the [master
branch](https://github.com/henriquesposito/poldis) for the latest
release and to the [develop
branch](https://github.com/henriquesposito/poldis/tree/develop) for the
exciting, things happening but not yet ready to be released.
